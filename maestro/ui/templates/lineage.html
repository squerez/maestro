Connect a lineage backend

Maestro emits OpenLineage events on every pipeline run. To visualise the lineage graph, point it at a Marquez (or compatible) backend.

1 — Start Marquez

docker run -p 5000:5000 -p 5001:5001 marquezproject/marquez

2 — Configure your pipeline spec

lineage:
  enabled: true
  backend_url: http://localhost:5000
  namespace: my-team

3 — Start the UI with the lineage URL

from toolbox.maestro.ui.app import serve
serve(lineage_url="http://localhost:5001")
